Four ways to work with Backboard

They share one account, one memory, and every model. Start in any of them and pick up in the rest.

Get started Read the docs

R-CLI

An open-source coding agent for your terminal.

Inspect and edit files, run commands, search the web and use MCP servers, on whichever model fits. #1 on Terminal-Bench 2.1, MIT licensed.

Explore R-CLI

Studio

A desktop coding harness for AI-native software.

Repository-aware context, flexible model access, and project memory that carries across sessions. For macOS, Windows and Linux.

Explore Studio

Nash

One place for your whole team to use AI.

Every model, your email, files and calendar where you allow it, and a memory that stays yours. Open source, and self-hostable.

Explore Nash

API & Platform

AI infrastructure through one unified API.

Memory, RAG, routing, state and 17,000+ models behind one key, deployed in the cloud, your own cloud, on-premise or on-device.
