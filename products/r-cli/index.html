What it does

Model flexibility

Run the models that fit your requirements across frontier, open-source, local, or private deployments. Bring your own key for Anthropic, OpenAI, Google, OpenRouter, or any compatible endpoint such as Ollama, LM Studio and vLLM.

Context and memory

Give coding workflows persistent context across tasks, repositories, sessions, and iterative development cycles.

Tool use and execution

Enable agents to inspect files, modify code, run commands, test changes, and work through multi-step software tasks, kept reviewable through permissions and checkpoints.

Open and extensible

Inspect the harness, adapt workflows, add tools, change model providers, and integrate R-CLI into your own development environment. MIT licensed.
