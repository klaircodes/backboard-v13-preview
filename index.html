Backboard Labs

New R-CLI is #1 on Terminal Bench 2.1

Backboard is an AI efficiency lab. We build technology that makes AI faster, smaller, more capable, and less expensive to run.

AI has become remarkably capable, but running it well is still out of reach for most teams. The strongest models are too large to serve where the data lives. Systems forget what they were told yesterday. Every request costs more compute than it needs to, and choosing a model too often means choosing a single vendor. We started Backboard to close those gaps: smaller models, sharper memory, and deployment that stays yours, in the cloud, on-premise, or fully local.

Our work ships as one platform for memory, routing, context, tools, models, and state, and as the products built on it: R-CLI, Studio, Nash, and the Backboard API.

What we make

R-CLI, the coding agent. An open-source agent that runs in your terminal. Open it in a project and describe what you want: it inspects and edits files, runs commands, searches the web, and keeps its work reviewable through permissions and checkpoints. It runs on whichever model fits, and it is #1 on Terminal-Bench 2.1.

More on R-CLI

Studio, the desktop harness. A full desktop workspace for software work, not just code suggestions. Studio understands the files and structure of your repository, keeps context across sessions, and lets you choose the model for the task: frontier for hard reasoning, open for efficiency, private or local when the code cannot leave.

More on Studio

Nash, for the whole team. One place for everyone to use AI. Ask in plain words: Nash reads the email, files and calendar you let it, answers with whichever model is best, and remembers what you told it next time. It is open source, so a team can run it on its own servers.

More on Nash

The API, underneath it all. Memory, RAG, routing, state and more than 17,000 models behind one key, deployed in our cloud, yours, on-premise or on-device. The quickstart is a single request, and a thread and assistant are created for you.

More on the API

More from the same hardware

Inference that does more with less. We work on serving more AI requests with the same hardware, cutting latency and unnecessary computation so more users can be served without a proportional increase in infrastructure.

−70% model size, up to, with BackboardQuant

Smaller models, the same capability. We make powerful models smaller and more efficient without sacrificing useful capability. BackboardQuant compresses models by up to 70 percent while keeping what made them worth running, so they run on less expensive hardware.

Memory is the foundation

AI that remembers. A system is only as useful as what it can recall. We help AI retain, find, and use information more effectively, giving it the right knowledge at the right time.

90.1LoCoMo 93.4LongMemEval

Measured against public benchmarks. Backboard was the first AI platform to lead both major memory benchmarks at once, with 90.1 percent on LoCoMo and 93.4 percent on LongMemEval.

Your data, your models

Private and local by design. We run capable AI closer to your data, including private, on-premise, and local environments, so sensitive information and the intelligence built on it stay where you need them.

Choice over lock-in. One account reaches more than 17,000 models. Memory, context, and state travel with you between them, rather than staying behind with a single provider.

Learning by shipping

Agents that reason, adapt, and act. We explore new ways for AI systems to work on real tasks, end to end. Our open-source coding agent, R-CLI, is #1 on Terminal Bench 2.1.

Research and product together. Every result we publish runs in a product someone can use the same day. Products keep the research honest, and the research keeps the products ahead.
