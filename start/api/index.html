Start with the Unified API

One key. Memory, 17,000+ models, RAG and threads.

Four steps

  1. Create your account

    Free to start, no credit card required.

    Create your free account

  2. Create an API key

    In the dashboard at app.backboard.io, open Settings, then API Keys, and create a key.

  3. Install the SDK

    pip install backboard-sdk # or: npm install backboard-sdk

  4. Send your first request

    from backboard import BackboardClient

    client = BackboardClient(api_key="YOUR_API_KEY")
    response = await client.send_message(
      "What is the capital of France?",
      llm_provider="openrouter",
      model_name="moonshotai/kimi-k2.6",
      stream=False,
    )

    A thread and assistant are created for you.

The full walkthrough is in the quickstart. More on the API page.
